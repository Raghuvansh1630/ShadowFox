# Boston House Price Prediction

## Objective
Predict Boston house prices using housing-related features and Linear Regression.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Workflow
1. Load dataset
2. Handle missing values
3. Perform EDA
4. Train Linear Regression model
5. Evaluate using MSE and R²

HousingData.csv
