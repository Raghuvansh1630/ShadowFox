# DistilBERT Sentiment Analysis and Exploration

## 📌 Project Overview

This project explores the capabilities of DistilBERT, a lightweight version of BERT, for sentiment analysis. The model is implemented using Hugging Face Transformers and tested on different text inputs to analyze its contextual understanding and prediction capabilities.

---

## 🎯 Objectives

- Implement a pre-trained Language Model (LM).
- Explore the model using different text inputs.
- Analyze contextual understanding.
- Visualize confidence scores.
- Study strengths and limitations.
- Understand ethical considerations in NLP.

---

## 🛠 Technologies Used

- Jupyter Notebook

- Seaborn

---
